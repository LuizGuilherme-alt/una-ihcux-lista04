# Sistema Robusto - Tratamento de Erros

Este projeto foi desenvolvido com foco na 5ª Heurística de Nielsen: **Prevenção de Erros**.

## 💡 O que é try-catch?

O bloco `try-catch` é utilizado para capturar erros que podem ocorrer durante a execução do programa.

- `try`: onde o código é executado normalmente.
- `catch`: captura erros e evita que o programa "quebre".
- `finally`: executa independentemente de erro ou não.

## 🚨 Problema sem tratamento

Sem tratamento de erro, se o usuário digitar letras em vez de números, o sistema fecha abruptamente.

## ✅ Solução aplicada

Com o uso do `try-catch`, o sistema:

- Não fecha inesperadamente
- Mostra uma mensagem amigável
- Orienta o usuário a corrigir o erro

## 🎯 Conexão com IHC

Esse tratamento melhora a experiência do usuário, pois:

- Evita frustração
- Mantém o controle com o usuário
- Aumenta a confiança no sistema
